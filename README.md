# Venue Connect

Venue Connect is a digital platform designed to connect people searching for event venues with venue owners.

The system allows users to discover venues using AI features, view venue information, check availability, make bookings, and interact with venue providers.

## Project Structure

```text
frontend/       Frontend application
backend/        Backend application
database/       Database scripts and database documentation
api/            API documentation
docs/           System analysis and design documentation
tests/          Application and API tests
```

## Git Branches

* `main` - Stable production-ready version
* `develop` - Main development branch
* `feature/*` - New features
* `fix/*` - Bug fixes
* `docs/*` - Documentation changes

## Development Workflow

1. Pull the latest changes from `develop`.
2. Create a feature branch.
3. Develop and test your changes.
4. Commit your changes.
5. Push your branch to GitHub.
6. Create a Pull Request.
7. Have the changes reviewed.
8. Merge into `develop`.
